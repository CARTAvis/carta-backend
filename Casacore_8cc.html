Checks that the images named in an image expression are inside the given folder.

casacore opens the images in an expression itself, so the names are found here the way its lexer finds them and checked before it parses the expression. Nothing is checked if the folder is /.

Parameters
[in]expressionThe image expression.
[in]directoryThe directory that names in the expression are relative to, as GetPathInFolder() returned it.
[in]folderThe folder the images must stay inside.
Exceptions
casacore::AipsErrorIf a name is outside the folder, or is itself a saved image expression.

const std::string &  folder,
bool  expand = true 
)

Checks that a path is the given folder or inside it.

The check works on the text of the path, so symlinks inside the folder can still point anywhere. Open the returned path, not the input: in the text link/.. is just the folder, but the OS would follow link first and go up from where it points. To check where symlinks lead instead, give it paths that have had their symlinks followed.

Parameters
[in]pathThe path to check.
[in]folderThe folder the path must stay inside.
[in]expandWhether to expand environment variables in the path first, as casacore will if it is given the path.
Returns
The path with . and .. removed, or an empty string if it is outside the folder.

◆ IsGildasUnit()

bool IsGildasUnit ( const casacore::String &  unit)

Check if input unit string is in the format used by the GILDAS CLASS software.

This function uses regex to check if unit is in the GILDAS CLASS software format "unit (Ttype)" where the "type" describes the temperature T. It also tests for casacore Unit name changes where " " and "*" are replaced with ".". For example: "K (Ta*)" --> "K.(Ta.)" in casacore.

◆ NormalizeUnit()

void NormalizeUnit ( casacore::String &  unit)

Normalizes a given unit string to conform to standard Casacore unit conventions (case-sensitive).

This function converts various unit representations into their standardised Casacore equivalents. It replaces non-standard units with correct forms, fixes case inconsistencies, and removes invalid characters. Additionally, it attempts to map the unit to a valid Casacore unit using UnitMap::fromFITS and UnitVal::check.

Note
If the unit contains a recognized prefix, the function attempts to normalise with and without the prefix.
Warning
If the unit cannot be resolved to a known Casacore unit, it remains unchanged.
Exceptions
casacore::AipsErrorCaught internally when Casacore unit conversions fail.
